1. 需求描述
IoTDB 当前仅能通过 DataRegion 或 DataBase 粒度统计存储空间，无法直观了解各表占用磁盘资源的差异。
本功能提供 SQL，支持展示 table/pattern（树模型） 级的存储空间使用统计。
2. 产品调研
2.1 客户使用场景调研
气象局存管系统（表模型）
用户 USER_A 拥有数据库 A下每张表的读写权限，且可查询该库下各表的存储占用情况；每张表设有存储容量阈值，当库 A 中某一张表的存储占用达到阈值时，超级管理员将收回 USER_A 对该表的写入权限，防止资源过载导致服务异常
开源用户

宝武在 E4 侧需要统计每个基地的磁盘占用（树模型）
E4 侧在一个 db 下汇聚了多个基地的数据，路径形如 root.db.基地.XXXXX
需要统计每个基地的磁盘占用情况

3. 功能定义
3.1 功能描述
本功能在 SQL 层面提供一个命令，用于展示指定表或 pattern（树模型）的磁盘空间占用情况，包括 ChunkGroup 的大小和 Metadata 大小。系统通过收集分布式节点上该表的物理文件大小信息，汇总后以结果集形式返回。
本功能统计的是 TsFile 中数据的真实大小，因此不会考虑 mods 删除的情况
3.2 功能定义
起始支持版本
2.0.8.2
表模型
information_schema 中增加一个 table_disk_usage 系统表，支持通过查询此系统表
通过系统表进行查询时，不显示 view，在过滤条件中指定不存在的 table 或 view 时返回空结果集
系统表
列名 | 列类型 | 含义
database | string | Database 名
table_name | string | 表名
datanode_id | int32 | DataNode 节点 id
region_id | int32 | Region id
time_partition | int64 | 时间分区 id
size_in_bytes | int64 | 占用磁盘空间(byte)
树模型（非标准 SQL）
ScalashowDiskUsageStatement    : SHOW DISK_USAGE FROM pathPattern     whereClause?    orderByClause?    rowPaginationClause?    ;pathPattern    : ROOT (DOT nodeName)*    ;
Pattern 用于匹配设备，需要使用 root 作为开头，路径的中间节点支持 * 或 **
结果集表头
列名 | 列类型 | 含义
Database | string | Database 名
DataNodeId | int32 | DataNode 节点 id
RegionId | int32 | Region id
TimePartition | int64 | 时间分区 id
SizeInBytes | int64 | 占用磁盘空间(byte)
3.3 非功能定义
3.3.1 性能要求
气象局有几百万 object 文件，预期是 2- 3s 返回统计结果，如果每次执行时进行一次即时的计算，可能执行较长时间，因此需要增加缓存进行加速
3.3.2 兼容性要求
无
